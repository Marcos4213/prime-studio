# Prime Studio — site + Raio-X de Presença

Static site (HTML/CSS/JS, no build step) for GitHub Pages.

- Settings: `CONFIG` at the top of `assets/app.js` (Google Agenda, WhatsApp, Meta Pixel, webhook).
- The cases are **sample projects** (illustrative model pages). Replace them with real cases in `CASES` in `assets/app.js`.
- `shots/`: test screenshots.
